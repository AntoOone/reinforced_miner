# The reinforced miner

This is a small tool I made to play with the concept of reinforcement learning

![](/resources/screenshot.png)

The project uses the [Processing](https://processing.org/) software, you will need it in order to compile the source files.

You can modify the terrain where the agent navigates on in the [grid_save](/grid_save.json) file.

You can also shape some of the terrain at runtime by using selecting the tiles on your right.
